# 03 进化与魔法

> 进化不是"升级"。**每一次进化都要花掉一个兽人一生的三次机会之一，而且可能失败、可能致残、可能死。**
> 魔法不是另一套系统。**魔法是进化的野路子，代价是污染。**

## 3.1 蜕变（Metamorphosis）

兽人一生有三次蜕变窗口，每个个体**只能蜕变 1–3 次**（取决于年龄、健康与是否血脉锁死）。

| 蜕变 | 年龄 | 前置 | 典型选择 |
|---|---|---|---|
| **启血** | 8 岁 | 无 | 定下血脉方向（提升某条血脉 +10，或唤醒一条暗池血脉） |
| **抉择** | 16–22 岁 | 无 | 主路线的第一个节点（血脉 / 嵌合 / 魔化） |
| **升华** | 35 岁以上 | 已蜕变 ≥1 次 | 路线的终极节点 |

### 蜕变流程

1. **备仪式**：需要祭坛（营地建筑）、**进化素**、以及该节点指定的素材（血脉精粹 / 魔素结晶 / 祖灵印记 / 异变器官）。
2. **结茧**：3–7 天，个体无法行动、无法自卫。部落必须保护他。
   - ⚠️ **迁徙途中无法蜕变。** 这让"什么时候停下来"成为一个真实的战术选择。
3. **掷骰**：`成功率 = 0.55 + 0.25×健康 + 0.15×祭坛等级 + 0.10×区域魔力 − 0.30×魔素污染`
4. **结果**：
   - 成功 → 获得节点能力
   - 失败（差 ≤0.15）→ 重伤，浪费材料，可重试
   - 大失败 → **血脉锁死**（永久不能再蜕变）或死亡

### 进化素（Essence）

唯一的通用进化货币。来源：

| 来源 | 数量 |
|---|---|
| 猎杀精英生物 / 魔物 | 2–8 |
| 从灾祸中幸存（按受灾规模） | 5–20 |
| 完成部落仪式 | 3–10 |
| 探索遗迹与化石点 | 5–15 |
| 吞噬异变器官 | 3–6 |

**进化素是稀缺的**：一个 10 人部落一年大约能积累 40–80 点，而一个终极节点要 60 点。所以"让谁进化"永远是残酷的排序问题——通常给最有希望把血脉传下去的那个。

## 3.2 四条进化路线

| 路线 | 需求 | 层数 | 代价 |
|---|---|---|---|
| **血脉进化** | 对应血脉血浓 ≥60 | 3 层 | 无额外代价，但路线固定、可预测 |
| **嵌合进化** | 已触发对应嵌合 | 3 层 | 需要两条血脉同时维持高位，配对压力大 |
| **魔化进化** | 某学派熟练度 ≥3 | 3 层 | **生育率与寿命下降**，不可逆，社交减益 |
| **部落进化** | 图腾与研究（不需要蜕变期） | 4 层 | 全族共享，但只能选一条文化路线，互斥 |

### 血脉进化示例：家猫线（影类）

| 层 | 节点 | 效果 |
|---|---|---|
| 1 | **影步** | 移动不留下痕迹，闪避 +15% |
| 2 | **双身** | 战斗中产生一个残影分身，承受一次攻击 |
| 3 | **无相** | 主动虚化 3 秒，免疫全部物理伤害，冷却 1 天 |

### 嵌合进化示例：天猎线（影 + 羽）

| 层 | 节点 | 效果 |
|---|---|---|
| 1 | **风牙** | 俯冲攻击附带穿刺，可击穿两层护甲 |
| 2 | **天穹之眼** | 高空视野，标记全图敌方目标 6 小时 |
| 3 | **天穹之主** | 可搭载 1 名同伴滑翔，实现**全队空中投放**（战略级，改变迁移路线选择） |

### 魔化进化示例：空间系

| 层 | 节点 | 代价 |
|---|---|---|
| 1 | **折跃** | 生育率 −20% |
| 2 | **折叠体** | 寿命 −15%，身上出现空间疤痕（社交 −30%） |
| 3 | **门** | **永久不育**，但可为全队开启跨区域传送门 |

**设计意图**：魔化路线的代价是**斩断血脉**。这意味着一个走上魔化终极的个体，是这个谱系的终点。玩家在做的是：用血脉的延续换一次战术/战略上的飞跃。这是一个真正的悲剧性选择，而不是数值优化。

### 部落进化示例：三条互斥文化路线

| 路线 | 1 层 | 2 层 | 3 层 | 4 层 |
|---|---|---|---|---|
| **祖灵道**（亡语） | 祖灵祭坛 | 记忆传承（死亡个体经验 50% 传给下一代） | 亡者议会（可咨询已故长老） | **祖灵降临**（召唤先祖化身参战） |
| **地脉道**（万形） | 魔素测绘 | 突变控制（可选择接受/拒绝突变） | 化石血脉活化 | **万血归一**（开启终局） |
| **铁牙道**（军事） | 兵役制 | 图腾武装 | 战争酋长 | **兽潮**（可召唤全族狂化） |

**互斥**：选定第 1 层后另两条路线永久关闭。这决定了终局走法。

## 3.3 九大魔法学派

学派本身**不消耗蜕变次数**——它是可以学的知识。真正昂贵的是**魔化进化**（用污染换力量）。

| 学派 | 亲和类群 | 代表法术 | 战术定位 |
|---|---|---|---|
| **空间** | 影类 | 闪现、储物、短距传送 | 机动、脱战、后勤 |
| **心灵** | 群类（狼、犬） | 群体链接、共享视野、士气鼓舞 | 团队增益 |
| **幻术** | 群类（狐） | 伪装、欺骗、契约标记 | 外交、潜行、控制 |
| **生命** | 疾类、角类（鹿、兔） | 治疗、催生、再生 | 续航、农业 |
| **风雷** | 羽类（鹰） | 疾风、视远、雷击 | 侦察、远程输出 |
| **亡语** | 羽类（鸦） | 读取亡者记忆、召唤祖灵、诅咒 | 情报、召唤 |
| **毒血** | 鳞类（蜥、蛇） | 剧毒、血祭、生命汲取 | 高爆发高代价 |
| **大地** | 角类（牛）、重类（熊） | 护盾、锻造、丰饶 | 防御、生产 |
| **潮水** | 重类（水獭） | 潮汐、净化、气候干预 | 区域改造、治污 |

### 交叉学派（需嵌合解锁）

| 交叉学派 | 组合 | 特色 |
|---|---|---|
| **梦境** | 心灵 + 亡语 | 预言、远程入梦、士气操控 |
| **暗影** | 空间 + 幻术 | 隐匿、暗杀、假象战场 |
| **轮回** | 生命 + 亡语 | 复活（代价极高）、衰老控制 |
| **龙焰** | 风雷 + 毒血 | 元素吐息、范围毁灭 |

### 学习途径

1. **图腾研究**（营地建筑，稳定但慢）
2. **祖灵低语**（花费进化素直接灌输，快）
3. **遗迹**（探索获得残卷，随机）
4. **与他族交换**（用物资/血脉换法术，需要关系值）
5. **偷学**（潜行窃取，失败会招致战争）
6. **血祭**（禁术：以族人性命换取，全族士气 −15）

**血脉亲和加成**：若个体有某学派亲和类群的血脉且血浓 ≥35，学习速度 ×2。**这是混血的第二个真实回报**——混血个体能学的学派更多。

## 3.4 魔素污染（Taint）

每施放一次法术累积污染。它不是蓝条，是**不可逆的形态改变**。

| 污染 | 阶段 | 效果 |
|---|---|---|
| 0–25 | 清澈 | 无 |
| 26–50 | **着痕** | 皮肤发光/异色瞳（外观改变），突变率 +50%，社交 −5 |
| 51–75 | **魔化** | 属性重分配（+灵性，−体魄），生育率 −30%，获得一项被动魔法本能 |
| 76–99 | **濒界** | 每次施法 10% 概率暴走（随机攻击最近目标） |
| 100 | **失控** | 变为**魔化兽**——永久离队成为地图怪物。**可能是你的第一代酋长。** |

### 污染的双向性

- **净化仪式**：降低污染 20–40 点，但**损失 1 级某学派熟练度**。
- **拥抱**：走魔化进化路线者可以将污染当作资源——污染越高，魔化节点效果越强（最高 ×2）。
- **魔潮期**：全图污染增长 ×2，但突变率 ×3。**这是本作最好的一次赌局设计**：潮汐期间你是收紧施法保平安，还是全力赌一波稀有血脉？

## 3.5 进化不可逆，且会被记住

- 除极少数「返祖」节点外，**进化不可撤销**。
- 每个个体的完整进化路径写入族谱，并自动生成叙事文本。
- 部落图腾柱上会刻下每一次重要进化的符号——**这是可以看的进度条，也是可以读的历史**。
- 灭绝个体的血脉若成功传递，其进化特征会以"血脉记忆"的形式在族谱中标注（例如：氏族中所有猫血脉个体都带有祖先「无相」的痕迹）。

**设计意图**：让玩家在 10 小时后打开族谱，看到的不是一张数值表，而是一部自己亲手造成的、无法挽回的编年史。

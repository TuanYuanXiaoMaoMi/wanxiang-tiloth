# 15 继嗣制度：一个部落在怎么记住「我是谁家的」

> 七种姓氏/继嗣模式，由知识树解锁，玩家可用信仰改制。
> 复现：
> ```bash
> ./tools/godot.sh --headless --script res://tools/debug_descent.gd   # 六种模式的氏族结构对照
> ./tools/godot.sh --headless --script res://tools/debug_reform.gd     # 改制全流程
> ```

## 15.1 为什么这不是「换个显示方式」

一开始的想法是"让玩家选姓氏规则"。但那样做出来会是个纯装饰的选项 ——
**如果制度只改名字、不改任何行为，那它就不是制度，是换肤。**

所以定了一条要求：**每一种模式都必须有机制后果**，而且后果要落在三个地方：

| 后果 | 落在哪 |
|---|---|
| 哪一半血统能传下去 | 氏族结构（母系下男性奠基者的姓一代就断） |
| 基因流的方向 | 从妻居 / 从夫居 → 联姻进来的是男是女 |
| 择偶范围 | 氏族外婚禁忌 → 同姓不婚 |

## 15.2 七种模式

| 模式 | 阶段 | 规则 | 机制后果 |
|---|---|---|---|
| **母名制** | 游团 | 无姓；名后挂母亲的名 + 子/女 | 从妻居 |
| **父名制** | 游团 | 无姓；名后挂父亲的名 + 子/女 | 从夫居 |
| **母系** | 氏族 | **原样继承母姓**（不取首字） | 从妻居；只有女性奠基者的姓能传下去 |
| **父系** | 氏族 | **原样继承父姓** | 从夫居；只有男性奠基者的姓能传下去 |
| **双系** | 酋邦 | 父姓首字 + 母姓首字 | 从夫居；姓氏本身记录混血 |
| **两可继嗣** | 酋邦 | 随**氏族更大的那一方**姓 | 从夫居；规则依赖世界状态，见 [docs/17](17-可扩展性实测.md) 17.4 |
| **双重继嗣** | 酋邦 | 双姓，**且同姓不婚** | 从夫居；氏族外婚 |

**母系和父系是"原样继承"，不是取首字。** 这是关键 ——
母系的意义就是这条线一直叫这个名字。代价是姓氏数量会一直很少（只有奠基女性的那几个）。

## 15.3 同一批奠基者，只换制度

| 模式 | 氏族结构（6 代后，人口 24） |
|---|---|
| 母名制 | 暖影女(5) 岑子(5) 始祖(3) 满眼女(1) — 10 组 |
| 父名制 | 尖息女(6) 苔脊子(4) 孤耳子(4) — 7 组 |
| **母系** | **暖(13) 獭(6) 暮(1) 日(1)** |
| **父系** | **日(12) 暮(7) 暖(1) 獭(1)** |
| 双系 | 日暮(6) 暮暖(5) 日獭(4) — 9 组，结构最丰富 |
| 双重继嗣 | 同双系（差别在外婚禁忌，不在名字） |

**母系和父系的姓氏集合完全不相交**（暖/獭 vs 日/暮）——
女性奠基者的线 vs 男性奠基者的线。制度真的决定了哪一半血统能传下去，
而不只是换了个写法。

## 15.4 阶段是这条曲线的灵魂

人类学上的论证是：**游团阶段父子关系说不准，只有母亲是确定的，所以只能记母系；
等到有了财产要往下传，父系才有意义。**

| 阶段 | 人口 | 解锁 |
|---|---|---|
| 游团 | ≤13 | 母名制、父名制 |
| 氏族 | 14–23 | + 母系、父系 |
| 酋邦 | ≥24 | + 双系、双重继嗣 |

阶段**由人口直接推导**，不另设一套进度条 —— 少一个要维护的状态。

## 15.5 改制：代价不只是信仰

```
改制开销 = 45 + 20 × 跨了几个阶段
```

信仰 +13.5/回合（上限 100），所以同阶段改制约 3.3 回合，跨阶段约 5–6 回合。

**但真正的代价落在人身上。** 守旧的人把改制当成对祖灵的冒犯：

```gdscript
static func reform_mood_delta(traits, magnitude):
    守旧  −9.0 × 幅度
    好奇  +7.0 × 幅度
    怯懦  −3.0 × 幅度
    勇猛  +2.0 × 幅度
```

实测一次「母名制 → 母系」的改制：**7 人心情变差，6 人变好**。

> 制度是可以变的，但变的时候要有人不高兴。这比扣一笔抽象的信仰值有说服力。

### 改制时重新登记氏族名

名后挂父母名的制度里，记下来的是「碎息女」这样的**临时标记**。
一旦改成有姓的制度，这种标记会被原样继承下去，变成一个叫「碎息女」的氏族（实测出现过）。

所以改制时会**重新登记**：去掉性别后缀，还原成家族名。

### 过渡是看得见的

**已出生的人不改名，新规矩只管之后出生的孩子。**

```
改制前出生   碎息        短鳞        断息        石鬃        ← 无姓
改制后出生   断息·寒翼   碎息·火心   碎息·苍雨              ← 随母姓
```

同一个部落里两种名字形式并存 —— 玩家能一眼看出这次改制是哪一年发生的。
每个人身上都存着 `descent_mode`（出生时的制度），所以这个过渡不需要额外的状态。

## 15.6 顺带修掉的择偶问题

给择偶加「关系好的人更容易在一起」时，我一开始写了：

```gdscript
score += relation(fid, mid) * 0.004     # 量程 ±0.4
```

而 `chimera_score` 的量程是 **0–1**，`CHIMERA_KIN_WEIGHT × kin` 最多 0.9。
也就是说**好感项占了整个评分范围的 40%，直接盖过了遗传优化** ——
择偶退化成"只跟喜欢的人配"，嵌合率下滑。

改成 `0.0006`（量程的 6%）当作微调。

> **往一个已有评分函数里加新项时，第一件事是量它的量程。**
> 这不是数值调参问题，是"新项会不会把主项挤掉"的结构问题。

## 15.7 节奏回归与一个诚实的说明

| | 之前 | 现在 |
|---|---|---|
| 最小 | 14 | **16** |
| 中位 | 24 | **20** |
| 最大 | 28 | **30** |

仍在 15–40 的目标窗口内。

**但我要说清楚这个位移是怎么来的**：两次测量的「起点承载力」一列完全相同
（17.8 / 16.8 / 17.3 / …），说明**大陆是同一批**；变的是部落 ——
新增的取名重试循环消耗了不同数量的随机数，于是**这 8 个种子变成了 8 个不同的奠基者掷骰**。

所以这是抽样差异，不是机制退化。要严格归因，需要把奠基者基因组固定住再对照，
那是测试台架要改的事，这一版没做。**中位数 20 回合（20 分钟）见到第一次强制迁徙**，
比 24 更早到达那个决策点，我认为可以接受。

## 15.8 遗留

- **联姻入口还没实装。** `incoming_sex()` 已经写好了「从妻居进来的是男人」这套逻辑，
  但 `gene_flow_per_year` 默认是 0，界面里也没有联姻按钮。
  这是 [docs/02](02-血脉与遗传系统.md) 里姓氏收敛的解药，也是把配对权交给玩家的入口。
- **双重继嗣只有一条机制**（同姓不婚）。真实的双重继嗣里，父系管财产与地位、
  母系管通婚禁忌 —— 后半句有了，前半句要等地位/财产系统。
- 改制没有冷却期，理论上可以反复横跳刷心情。目前靠信仰开销挡着，但可以更严。

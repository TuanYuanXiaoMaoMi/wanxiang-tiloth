# 14 个体人格、关系与个人史

> 让每个人有自己的性情、爱好、想法、关系和故事。
> 复现：
> ```bash
> ./tools/godot.sh --headless --script res://tools/debug_persona.gd   # 人格层诊断
> ./tools/godot.sh --headless --script res://tools/check_fonts.gd     # 字体覆盖检查
> ./tools/godot.sh -- --screenshot-lineage                            # 人物档案界面
> ```

## 14.1 一条设计红线

这一步最容易做砸的方式是：**随机生成一堆性格标签和背景故事，然后它们不影响任何决策。**
那玩家看到的是一列形容词和一段编出来的往事，读两次就再也不看——**那不是"有思想"，那是噪音。**

所以定了一条硬规矩：

> **每一条性情都必须明确写出它改的是哪个数。**

| 性情 | 改什么 | 具体 |
|---|---|---|
| **勤勉** | 劳动产出 | `labor_capacity() × 1.12` |
| **怠惰** | 劳动产出 | `× 0.88`，但心情基准 +8 |
| **贪食** | 每人每日口粮 | `× 1.12` |
| **节食** | 每人每日口粮 | `× 0.90` |
| **亲和** | 关系增长速率 | `× 1.9` |
| **孤僻** | 关系增长速率 | `× 0.35` |
| **恋家** | 距离惩罚 | 靠近营地 ×1.14，远处 ×0.90 |
| **远行癖** | 距离惩罚 | 靠近营地 ×0.93，远处 ×1.16 |
| **勇猛 / 怯懦** | 危险耐受 | 已挂好数值，留给灾祸与冒险派遣 |
| **好奇 / 守旧** | 学习与凝聚 | 已挂好数值，留给蜕变与魔法系统 |

而且这个"挂钩"不是写完就算——它必须真的进结算：

```gdscript
# world_state._production_from_sites()
for id in ws:
    var b: Beast = tribe.beasts[id]
    var per := base * b.labor_capacity()          # 年龄 × 性情 × 心情
        * Persona.distance_mult(b, dist)          # 恋家 / 远行癖
        * Persona.site_pref_mult(b, kind)         # 爱好对口
```

**产出从"人数 × 统一速率"改成了逐个个体结算。** 在这之前，勤勉和怠惰只是列表里的两个字。

## 14.2 爱好：让「把谁派到哪里」变成真决策

每个人有 1–2 个**偏好工作类型**（采集 / 狩猎 / 伐木 / 采石 / 采晶 / 采药）。

- 干对口的工作：产出 **+18%**
- 干不对口的工作：产出 **−5%**

自动派工也改成**按「能力 × 距离偏好 × 工作偏好」挑人**，而不是单纯按距离填格子。
实测一晚之后的心情差值很明显：

```
火·碎蹄   心情 98   想法：「这活儿我干得顺手。」     ← 派到采集点，爱好对口
骨·暗脊   心情 61   想法：「这活儿真烦。」           ← 派到不喜欢的地方
风·苍尾   心情 69   想法：「我更想干别的。」
```

**玩家看到这句话就会想去调整指派——这就是这个系统存在的意义。**

## 14.3 关系：−100 到 +100，由真实互动驱动

| 驱动 | 效果 |
|---|---|
| **亲属** | 由谱系亲缘系数换算的基础值：父母/同胞 φ=0.25 → **+35**；表亲 φ=0.0625 → **+9** |
| **同一工作点共事** | 每回合 **+0.8**（乘上双方的「亲和」系数） |
| **休息所配对成功** | **+5** |
| **法术强制配对** | **−42** |
| **没有互动** | 每回合向 0 衰减 **1.5%** |

### 关系反过来影响什么

1. **协作产出**：同一个工作点上的人，平均好感度换算成 **±14%** 的产出。
   生死之交一起干活更快，仇人凑一块互相拖后腿。
2. **自然择偶**：休息所里优先撮合最合得来的一对，而不是随机配。
3. **伴侣**：好感度到 **+62** 且双方都没有伴侣时自动确立，会写进两个人的个人史。

### 亲属用专门的称谓

`kin_word()` 会算出「父 / 母 / 子 / 女 / 同胞 / 半同胞 / 亲戚」，
关系标签对亲属也另有一套说法——**母亲和女儿显示成「好友」很怪**：

```
暗·苍眼        至亲  +41 （母）
暗灰·霜牙      至亲  +36 （同胞）
灰·苍喙        至亲  +35 （父）
灰暗·雪角      至亲  +35 （亲戚）
```

### 法术强制配对的代价，现在落在两个人身上

[docs/02](02-血脉与遗传系统.md) 里那个"士气 −14"太抽象了。现在：

```gdscript
tribe.add_affinity(male, female, -42.0)   # 他们互相恨上了
ba.mood -= 26.0                            # 各自的心情也塌了
tribe.note(ba, "祖灵把我和%s按在了一起。我不会忘记这件事。")
```

**玩家能在人物档案里看到这笔账。** 这比一个抽象的数字有说服力得多。

## 14.4 个人史：只记真实发生的事

个人史**不编造背景**，只记录游戏里真的发生过的事件：

- 出生：「出生在暗灰氏，母亲是灰·苍掌。」
- 生育：「生下了暗灰·霜牙。」
- 迁徙：「拔营启程，前往灰烬口。」「抵达灰烬口。上一个营地是灰水口。」
- 死亡（记在**活着的人**身上）：「暗·苍眼死了（58 岁）。」——伴侣心情 −24，子女 −11
- 法术强制配对：「祖灵把我和X按在了一起。我不会忘记这件事。」
- 确立伴侣：「和X结成了伴侣。」

上限 40 条，超出丢最旧的。**因为每一条都来自真实事件，所以读起来是传记，不是设定文案。**

## 14.5 想法：一句会变的话

`Persona.think()` 按优先级检查当前处境，返回一句话：

| 优先级 | 触发 | 输出 |
|---|---|---|
| 1 | 刚被法术强制配对 | 「祖灵把我和X按在一起。这件事我不想提。」 |
| 2 | 饱食 < 35 | 「肚子空得发慌。」 |
| 3 | 在途迁徙中 | 「还要走多久？」 |
| 4 | 伴侣刚死 | 「他不在了。剩下的事得我自己扛。」 |
| 5 | 有伴侣 | 「和X一起干活，日子还过得去。」 |
| 6 | 刚生孩子 | 「我的孩子。希望他别像我一样。」 |
| 7 | 年龄 > 寿命 × 0.85 | 「我活得够久了。」 |
| 8 | 在爱好对口的工作点 | 「这活儿我干得顺手。」 |
| 9 | 在不对口的工作点 | 「这活儿真烦。」 |
| 10 | 兜底 | 按性情说话（勤勉→「还有活没干完。」） |

每回合重算。**这是最便宜、也最有效的一招**——一句话就让人有了当下的处境感。

## 14.7 这一版踩的两个坑

### 坑 1：`mood_factor` 把全员产出砍了 3.6%

```gdscript
# 错的：基准心情 70 时只有 0.964，等于给所有人凭空减了 3.6% 产出
func mood_factor() -> float:
    return 0.88 + 0.12 * clampf(mood / 100.0, 0.0, 1.0)

# 对的：以基准心情（70）为 1.0 来标定
func mood_factor() -> float:
    return clampf(1.0 + (mood - 70.0) / 100.0 * 0.25, 0.78, 1.10)
```

**任何"新加的系数"都必须以它的默认状态为 1.0 来标定**，否则它就是一个隐蔽的全局削弱 ——
和 [docs/12.3](12-可见个体与随机大陆.md) 里那个「距离惩罚悄悄砍掉 25% 产能」是同一类错误，**我又犯了一次**。

后果：迁徙节奏整体前移，8 个种子的最小值从 18 回合掉到 13 回合。

### 坑 2：字体缺字是静默的

扫描 1662 个唯一汉字后发现 **7 个常用字没有字形**：敌、杀、杂、稳、虑、**远**、迟。

根因：**Godot 的 `SystemFont` 在 `font_names` 里只挑第一个匹配到的字体，不做逐字回退。**
而 macOS 的 **PingFang SC 恰好缺这几个字**，我又把它排在了第一位 ——
于是界面上的「远行癖」渲染成了别的字。

修法两条：主字体换成实测能全覆盖的 Hiragino Sans GB，同时挂一串 `fallbacks` 兜底。
并写了 [tools/check_fonts.gd](../tools/check_fonts.gd) 把项目里**所有**文案的汉字逐个验一遍：

```
扫描到唯一汉字 1665 个
有字形 1665 个　缺字形 0 个
✅ 全部覆盖
```

> **缺字不会报错、不会崩，只会静默地渲染成豆腐块或错误的替代字形。**
> 这类问题在自检里永远是 0 错误 —— 只能靠一个专门的工具去抓。

## 14.8 刻意接受的代价：节奏方差变大了

加上性情之后，8 个随机大陆的迁徙回合分布：

| | 之前 | 现在 |
|---|---|---|
| 最小 | 18 | **14** |
| 中位 | 24 | **24** |
| 最大 | 27 | **28** |

**中位数没动，但尾部变宽了。**

原因很直白：性情是随机的。**一家子贪食 + 怠惰的部落确实会垮得更早。**
而且这里有一个正反馈在放大它：产出低 → 饱食下降 → 劳动系数下降 → 产出更低。

我**决定不去把它磨平**：

> 肉鸽本来就应该有"这一局出生的都是些什么人"的运气成分。
> 把每个种子都压进一个窄区间，等于把这个游戏最有趣的东西之一抹掉。

代价是首局体验可能偏难（14 回合 ≈ 14 分钟就见到第一次压力）。
如果测试下来确实太陡，正确的解法是**给玩家一个应对手段**（比如配给制度、把贪食的人单独分派），
而不是把性情的数值调小 —— **问题在"玩家没得选"，不在"性情太强"。**

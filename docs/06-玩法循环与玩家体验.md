# 06 玩法循环与玩家体验

> ### ⚠️ 本文已过时：游戏已改为**回合制**
> 一个回合 = 一季 = 30 天，「暂停 / 1x / 4x / 16x」的速度档已删除，改为一个「结束回合 ▶」按钮。
> 下文的时间结构与自动暂停规则保留作为设计记录，但已被回合边界取代。
> 为什么改、改完节奏是否还在、以及**为什么这次改造零返工**，见 [13-回合制改造](13-回合制改造.md)。

## 6.1 时间结构

| 单位 | 换算 | 现实时间（1x 档） |
|---|---|---|
| 1 日 | 4 节拍（晨/昼/昏/夜） | 2 秒 |
| 1 季 | 30 日（春/夏/秋/冬） | 1 分钟 |
| 1 年 | 4 季 = **120 日** | 4 分钟 |
| 1 世代 | 12–15 年 | 50–60 分钟 |
| 兽人寿命 | 45–65 年 | — |

**注意：一年是 120 天，不是 365 天。** 时间尺度是全局常量，必须在写第一行模拟代码之前钉死。

### 速度档

`暂停 / 1x / 4x / 16x`。**常用档是 1x（1 年 = 4 分钟）。**

> ⚠️ **实测修正**（见 [11.7](11-资源耗竭与迁徙节奏实测.md)）：本节原先写着「常用档是 4x（1 年 ≈ 1 分钟）」，
> 但那与本作「单局 8–15 小时」自相矛盾：
>
> ```
> 8-12 世代 × 12-15 年 = 96-180 游戏年
> 4x 下：96-180 分钟 = 1.6-3 小时   ← 与 8-15 小时差 4 倍
> 1x 下：96-180 年 × 4 分钟 = 6.4-12 小时   ✅
> ```
>
> 正确用法：**1x 是常态**，4x 用来跳过无事发生的空档，16x 用来等资源恢复。

**自动暂停规则**（可在设置中逐条开关）：
- 灾祸前兆出现
- 有蜕变窗口可用
- 妊娠结果产生（新生儿诞生）
- 迁徙抵达
- 发现遗迹
- 士气 / 饱食跌破阈值
- 个体死亡（仅"有名字的"个体）

**设计意图**：让玩家能安心开 16x 等资源恢复，同时保证任何**需要决策的事**都会把时间拉回暂停。这是模拟经营游戏最重要的一条体验设计。

### 世代更替

- 每 12–15 年，第一代全部退场
- 世代更替时触发一次**编年史生成**：从真实发生的事件里生成一段 200–400 字的部落史诗
- 玩家可以随时导出全部编年史为文本文件

## 6.2 玩家身份：祖灵

| 能做 | 不能做 |
|---|---|
| **低语**：向个体给出倾向（进哪条进化路线、和谁配对） | 直接控制个体移动与战斗指令 |
| **祝福**：消耗信仰提升受孕率、蜕变成功率 | 强制配对（个体可以自行结合） |
| **律令**：设定部落政策（采集优先级、对外姿态、生育态度） | 无视资源强行建造 |
| **显现**：消耗大量信仰，直接干预一次（如降下神谕平息内讧） | 复活死者 |
| **派遣**：组建冒险小队前往节点 | 保证小队全员生还 |
| **记忆**：查看族谱、编年史、遗迹信息 | 修改已发生的历史 |

**为什么要这样设计**：
1. 世代更替不会打断玩家身份——你比个体活得久
2. 减少微操（个体自主工作），让玩家聚焦在**配对、进化、迁徙**三个决策上
3. 玩家的手是**间接的**，所以个体自作主张是合理且有趣的，而不是 AI bug

**信仰值**：祖灵的行动货币，来自仪式、图腾、传说、灾祸幸存。**它是唯一一种不可采集的资源**——只能靠部落的信念生产。这鼓励玩家在"效率"之外经营"意义"。

## 6.3 三层循环

### 五分钟循环（操作层）

```
看指标 → 调整政策 → 指派采集/狩猎 → 处理一个事件 → 看谱系规划器
```

### 一小时循环（世代层）

```
一个世代跨度内：
  繁衍 2-4 胎 → 完成 1-2 次蜕变 → 打一场灾祸 → 攒够或耗尽资源
  → 决定：留下（继续榨）还是迁徙（放弃一切）
```

### 一局循环（谱系层）

```
8-12 个世代中：
  第 1-3 代：建立基础血脉组合，摸索区域
  第 4-6 代：第一次被迫迁徙，接触外部势力，I 系数危机
  第 7-9 代：嵌合个体成形，进化树上行，部落分裂扩散
  第 10-12 代：锁定终局路线，押上全部资源
```

## 6.4 决策密度目标

**每 5–10 分钟至少一个"不可逆的重大决策"。**

| 决策 | 不可逆性 |
|---|---|
| 配对 | 生下来就不能退货，且 I 系数永久累积 |
| 蜕变节点 | 不可撤销 |
| 部落进化路线 | 三选一后另外两条永久关闭 |
| 建造图腾柱 | 钉死大量资源，且拖慢迁徙 |
| 迁徙 | 沉没成本全损 |
| 留守名单 | 直接决定生死 |
| 分家 | 制造一个会长大的孩子，也可能是敌人 |

**设计红线**：如果游戏出现连续 10 分钟只有"等资源攒够"的状态，说明某个系统的产出速率需要调整。

│ 兽人列表 │                                  │  上下文面板       │
│ (按血脉  │        地图视图 ⇄ 营地视图        │  · 选中个体详情   │

├──────────┴──────────────────────────────────┴──────────────────┤

```

**可读性要求**：
- 血脉用**图标 + 花纹 + 色相**三重编码，绝不只靠颜色（混血个体本来就杂色）
- 每个个体在列表里的小头像**就是**他的血脉组合的实时渲染（部件组合，见 [08](08-美术音频与开发路线图.md)）——玩家不看数字也能看出血脉变化
- 指标条上的每一盏灯鼠标悬停必须给出**"为什么现在是这个值"的一句话归因**

## 6.6 谱系规划器（最重要的界面）

一个独立的全屏界面，功能：

```
┌──────────────────────────────────────────────────────────────┐
│  父：灰烬（家猫68/鹰55/狼12）   母：长耳（兔71/鹿40/猫9）      │
├──────────────────────────────────────────────────────────────┤
│  子代血脉期望                                                 │
│   家猫  ████████░░░░░░  34 ± 6     （潜征）                   │
│   鹰    █████░░░░░░░░░  27 ± 6     （隐没）                   │
│   兔    █████████░░░░░  36 ± 6     （潜征）                   │
│   鹿    ████░░░░░░░░░░  20 ± 6     （隐没）                   │
├──────────────────────────────────────────────────────────────┤
│  嵌合触发概率：影+群 4% ／ 影+羽 0% ／ 疾+角 0%               │
│  I 系数：0.13（中度）→ 生育率 −25%，缺陷概率 15%              │
│  突变概率：14%（当前节点魔力浓度 0.68）                        │
│  缺陷风险：无面携带者 × 一方 → 子代 5% 概率患魔素病            │
├──────────────────────────────────────────────────────────────┤
│  [建议：不推荐]  原因：两方无血脉 ≥35 的组合，无法产生嵌合；   │
│  建议改为 灰烬 × 鹰血个体，可把影+羽嵌合概率提到 61%           │
└──────────────────────────────────────────────────────────────┘
```

**要求**：
- 30 秒内能读懂一对组合值不值得
- 显示**概率分布**而不是平均值（遗传是概率的，UI 不能撒谎）
- 给出机器建议，但建议可以是错的（玩家有最终决定权）
- 支持**三代预览**：可以看"如果这个孩子和 X 结合，孙辈如何"

**没有这个界面，遗传系统就会退化为抽卡。这是必须最优先做的 UI。**

## 6.7 冒险派遣层

- 派遣 3–5 人小队前往已侦察节点，持续 3–15 天
- 表现形式：**节点地图 + 事件卡 + 轻回合战斗**
- 事件来源：遗迹、生物、其他部落、自然灾害
- 战斗简化：自动结算为主，玩家可在关键回合插入技能指令（每场 3–5 次决策）

**设计意图**：冒险层的目的是**把个体带回部落层并改变它**——带回化石血脉、异血素材、外来配偶、记忆与情报，或者带回一具尸体和他没来得及传下去的血脉。冒险本身不是玩法主体，是**给遗传系统供料的水泵**。

## 6.8 四种终局

| 终局 | 条件 | 结尾基调 |
|---|---|---|
| **初兽**（纯化） | 某个体单一血脉血浓 = 100 且 I 系数 < 0.03，完成升华仪式 | 神话。那个兽人变回初兽的一块碎片，部落跪拜 |
| **新物种**（万血归一） | 全大陆 `blood_pool` 覆盖全部 16 血脉，BDI 落在 0.45–0.65，存活亲族部落 ≥5 | 创造。玩家**命名一个新血脉**，它进入元进度 |
| **文明**（定居） | 知识 ≥90，人口 ≥50，建成城市，连续 3 年不迁徙 | 告别。游牧时代结束，祖灵退入图腾 |
| **沉睡**（灭绝） | 人口 = 0 | **不是 Game Over**。生成"大陆史"条目，遗迹写入世界池 |

### 灭绝不是失败界面

当最后一个人死去，游戏不会黑屏。它会显示：

```
大陆史 · 第七纪 · 条目 214
「短耳氏」于绿喉的灰水湾定居四十一载。
第四代酋长灰烬（家猫68/鹰55）死于产褥热，未留下子嗣。
其部众在严冬中散尽。图腾柱尚存，刻有十一个符号。
```

然后提供一个按钮：**「下一个部落」**。新存档的地图上，灰水湾会有一座废弃营地，图腾柱还在。

## 6.9 元进度：血脉种子

- 达成「新物种」终局可**命名一条自定义血脉**，定义它的名称、主副属性、天性、外观部件参数
- 这条血脉进入**世界血脉池**，在后续存档的某些区域 `blood_pool` 中出现
- 上限 8 条自定义血脉（满了可以覆盖）
- 血脉种子是**唯一跨存档的进度**，且它是**内容**而不是数值优势——它让世界变得更丰富，不会让你更强

## 6.10 上手曲线：前 30 分钟

| 时间 | 内容 | 教学方式 |
|---|---|---|
| 0–3 分 | **8 人部落：一对父母 + 6 名成年子女**，1 个节点，1 座破窝棚 | 直接给资源数字，不弹教程 |
| 3–8 分 | 第一次配对 | 谱系规划器被强制打开一次，只用最简模式。**此时规划器会显示「全同胞，I 系数 0.250，生育率 −50%，死胎 30%」** |
| 8–15 分 | 食物曲线开始下跌 | 不提示，让玩家自己发现 `prey_stock` 在掉 |
| 15–20 分 | 第一个灾祸前兆 | 明确的高亮 + 归因说明 |
| 20–30 分 | 第一次迁徙决策 | 迁徙按钮第一次变红，并展示"留下会发生什么"的预测 |

**不写长教程。** 用一条不断收紧的资源曲线当老师。玩家在第 25 分钟亲手做出第一次"留下谁"的选择时，就学会了这个游戏的全部味道。

> ### ⚠️ 实测修正：开局必须是**一家人**，不是五个陌生人
>
> 我原先设计的是「5 名互无血缘的奠基者」。实测证明这会**让整个核心系统失效**：
>
> | 开局设定（8 人） | F > 0.25 所需世代 |
> |---|---|
> | 互无血缘的奠基者 | **14 代**（远超一个存档的 8–12 代） |
> | **一家人（2 父母 + 6 全同胞子女）** | **5 代** |
>
> 「5 个互不相识的陌生兽人」是**最乐观的遗传假设**，而它把近交压力推到了玩家永远看不到的地方。
> 「一对父母带着成年子女出走另立部落」既更现实，又让压力在第 5 代就到来。
>
> 而且这个开局的**教学效果是免费的**：玩家第一次打开谱系规划器，就会看到
> 「全同胞，I 系数 0.250，生育率 −50%，死胎 30%」——
> **第一分钟就理解了这游戏在讲什么，不需要任何教程文本。**

## 6.11 关于失败的态度

本作**不提供存档回溯**（可以存档，但读档会记录次数并显示在编年史里，作为一个轻微的自嘲彩蛋：*"这一代的祖灵反复修改了记忆，共 7 次。"*）。

**理由**：整个设计建立在"不可逆"上。配对不可逆、蜕变不可逆、迁徙的沉没成本不可逆、留守名单不可逆。如果玩家可以随手读档，**这四条全部失效**，游戏就退化成一个普通的经营模拟。

# 01 世界观与基调

## 1.1 大陆：缇洛斯（Tylos）

一片被**魔力潮汐**反复冲刷的巨型大陆。潮汐不是海水的潮汐，而是地脉中魔素的涨落周期——每约三百年一次大潮，期间大地的物理法则会轻微松动。

潮汐造成三个后果，它们直接是玩法：

1. **突变窗口**：大潮期，血脉突变率暴涨。这是新血脉诞生的方式，也是老血脉崩坏的方式。
2. **地貌改写**：潮汐会淹没低地、隆起山脉、让某些区域变成永久魔素污染区。**地图不是静态的**——一张经营了五小时的地图，可能因为你没预料到的地脉改道而变得一文不值。
3. **生态崩塌**：潮汐后的区域资源再生率可能永久改变（森林变沼泽，草原变盐碱地）。

大陆按纬度与地脉走向分为六大地理区，每区下辖 8–12 个可交互节点（详见 [04 部落经营与迁移](04-部落经营与迁移.md)）。

| 地理区 | 基调 | 主要生态 | 魔力浓度 | 特产资源 |
|---|---|---|---|---|
| **霜脊**（北） | 肃杀、匮乏 | 针叶林、冻原、冰湖 | 低 | 毛皮、琥珀、寒铁矿 |
| **绿喉**（中北） | 丰饶、短暂 | 温带森林、河网、草原 | 中 | 木材、药草、猎物 |
| **赤瘤**（中） | 病态、危险 | 魔素污染荒原、晶簇谷 | 极高 | 魔晶、异变器官 |
| **长滩**（中东） | 漂泊、贸易 | 海岸、盐沼、群岛 | 中 | 鱼盐、海琥珀、外来血脉 |
| **灰烬环**（南） | 古老、神圣 | 火山灰平原、石林、遗迹 | 高 | 黑曜石、祖灵印记 |
| **脉裂**（西南） | 迷宫、深渊 | 巨藤峡谷、地下河、洞窟 | 高 | 菌菇、深矿、化石血脉 |

**设计意图**：每个区都有**别处拿不到的东西**，所以迁徙永远不是"去资源最多的那格"，而是"这一代我要牺牲什么去换什么"。霜脊的寒铁矿是造图腾柱的唯一来源，但那里食物再生率感人。

## 1.2 万形种（Panmorphus）

大陆上的智慧兽人**同属一个物种**。学界叫他们「万形种」——万种形态，一个种。

这不是背景板，是这个世界的核心谜团：为什么猫、狼、狐、鹿、鹰、蛇能有共同祖先，且**任意两族都能生育后代**？

三条并存的解释，游戏里永远不会给出确定答案（每个部落的信仰选择其中一条，**这直接是部落文化系统**）：

- **祖灵说**（主流信仰）：太古的「初兽」在潮汐中把自己撕成碎片，碎片就是血脉。所有兽人都是初兽的后裔，所以能互相补全。→ 信仰此说解锁「亡语」学派与纯化路线。
- **地脉说**（异端/学者）：地脉魔素是共同的遗传溶剂，形态只是魔素的结晶方式。→ 信仰此说解锁突变率控制与「万血归一」路线。
- **外来说**（禁忌）：万形种不是原生物种，是被造出来的。大陆上有非兽人文明的遗迹在证明这点。→ 信仰此说解锁遗迹科技与特殊结局，但会降低全族士气。

**玩法含义**：物种解释不是设定文本，而是**可选的三条研究/信仰树**，互斥、各有独特进化节点。

## 1.3 兽人的生物设定

| 属性 | 设定 |
|---|---|
| 身量 | 0.9–2.6 米（血脉差异极大，大猫与牛可达 2.4 米以上） |
| 性成熟 | 8 岁 |
| 妊娠期 | 6–10 个月（受血脉影响，兔鼠系偏短，牛熊系偏长） |
| 自然寿命 | 45–65 年（进化可延长，魔化可能缩短） |
| 繁育间隔 | 约 2 年/胎，通常单胎，兔鼠系可达双胎 |
| 世代长度 | 约 12–15 年 |
| 语言 | 通用语 + 各血脉的"气味语"与肢体语（狼的耳位、狐的尾势是真实的语义系统） |

**寿命与世代的设计意图**：玩家在一个存档内必须看到 **8–12 次世代更替**，才能体会"我经营的是谱系不是个体"。所以寿命要短、世代要密。第一代兽人长老通常活不到你第二次迁徙——这会制造真实的情感重量。

## 1.4 已开化的势力（世界的层次感）

不是所有兽人都还在部落阶段。大陆上存在**定居文明**，它们把游牧部落视为野蛮人、资源、或潜在的联姻对象。

| 势力 | 构成 | 态度 | 功能 |
|---|---|---|---|
| **铁牙盟** | 狼 + 熊，军事寡头 | 掠夺/雇佣 | 提供武力交换与战争威胁 |
| **九尾商团** | 狐 + 猫，跨国贸易网 | 中立/唯利 | 稀有血脉、异域物资、情报 |
| **羽葬教团** | 鸦 + 鹰，处理亡者的神权组织 | 高压/传教 | 亡语魔法、祖灵印记，逼迫你改信 |
| **林母会** | 鹿 + 羊 + 兔，母系农业共同体 | 友善/排外 | 药草、粮食、定居路线的样板 |
| **蜥沼血祭团** | 蜥 + 蛇，活祭与血魔法 | 敌对/可交易 | 剧毒素材、血魔法，代价是人命 |
| **沙丘王朝** | 大猫，最古老的兽人国家 | 傲慢/宗主 | 政治、赋税、庇护，会要求你的部落臣服 |

**设计意图**：这六个势力是**迁徙的压力源与目的地**。你靠近谁，决定了你能换到什么血脉、被谁威胁、以及最后走向哪种终局。它们也会迁移、扩张、互相开战——世界不围着你转。

## 1.5 叙事语气

- **不是英雄史诗，是族群志。** 文案基调参考民族志与考古报告：克制的、有距离感的记录，偶尔露出残酷。事件日志写「第三代的『短耳』在迁徙途中死于产褥热，她的血浓 71 的猫血脉没有传给任何人。」
- **不写爽文。** 玩家的成就感来自"我算对了三代之后的血脉配比"，不是"我打赢了boss"。
- **自动生成的族谱史诗**：每次世代更替，游戏从真实发生的事件里生成一段编年史文字。玩家可以把它导出成文本——这是极低成本、极高情感回报的内容。
- **留白**：物种起源三说都保持模糊。玩家自己投票决定他相信哪个版本。

## 1.6 视觉与听觉基调

- **视觉**：手绘感的厚涂立绘（部件分层，见 [08](08-美术音频与开发路线图.md)）+ 俯视 2D 地图。配色从"苔绿/琥珀/骨白"出发，魔素污染区转为"紫青/锈红"。**血脉必须用图标与花纹区分，不能只靠颜色**（色盲可读性 + 混血个体本来颜色就杂）。
- **听觉**：环境层（风、虫、水流）随区域切换；部落层用不和谐但温暖的复调人声吟唱；魔素污染区加入低频嗡鸣。**迁徙途中是没有背景音乐的**——只有脚步、风和零星的风声乐器，直到新营地建立音乐才回来。这是一个很便宜但极其有效的情绪设计。

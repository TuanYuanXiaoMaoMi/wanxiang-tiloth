# 《万相缇洛斯》设计文档

> 工作代号 **VW**（Vast Wilds / 万相）。一款 Godot 4 的 **2D 兽人部落经营 × 血脉进化 × 迁徙生存** 游戏。

你扮演的不是某一只兽人，而是部落的 **祖灵**——一个跨世代延续的意志。
你照料的是一个 **血脉谱系**，而不是一群个体。资源会枯竭，灾祸会降临，你唯一的选择是：**留下来被榨干，还是带着血脉迁徙。**

## 一页速览

| 项目 | 设定 |
|---|---|
| 类型 | 2D 俯视·**回合制**部落模拟经营 + 卡牌化冒险派遣 + 轻回合战斗 |
| 平台 | PC（Windows / macOS / Linux），键鼠优先，手柄可后补 |
| 引擎 | Godot 4.7.x，GDScript，数据驱动（JSON 定义 + Resource 包装） |
| 视角 | 玩家 = **祖灵**（Ancestor Spirit），通过图腾、律令、仪式、派遣间接引导部落 |
| 时间 | **1 回合 = 1 季 = 30 天**；首次被迫迁徙在第 24 回合 |
| 核心幻想 | 「我的血脉在这片大陆上活了十二代，变成了谁也认不出的东西」 |
| 单局时长 | 8–15 小时，跨 8–12 个世代 |
| 终局 | 4 种：**初兽**（血脉纯化）／**新物种**（万血归一）／**文明**（定居建国）／**沉睡**（灭绝，遗迹留给下一个存档） |

### 核心循环

```
         ┌──────────────── 侦察与选址 ────────────────┐
         ↓                                            │
   扎营 → 采集/狩猎/繁衍 → 资源曲线见顶 → 压力累积     │
         ↑                    ↓                       │
         │             ┌──────┴──────┐                │
         │        灾祸爆发      近亲衰退               │
         │             ↓            ↓                 │
         │        赌一把进化   需要外来血脉            │
         │             └──────┬──────┘                │
         └──────────  迁徙决策  ──────────────────────┘
                        ↓
                   新区域 + 世代更替
```

**一句话张力**：部落越繁荣，脚下的土地就越快被吃空；而血脉要进化，又必须让部落足够繁荣去承受灾祸。**你被自己的成功推着往前走。**

## 五条设计支柱

1. **血脉是主角，兽人是载体。**
   个体寿命有限，会死、会老、会被遗忘。玩家真正经营的是血脉浓度、嵌合组合与族谱。因此玩家身份是祖灵而非酋长——世代更替不会打断玩家。

2. **「无生殖隔离」是核心策略层，不是设定噱头。**
   16 条血脉可以任意混血。但纯血会近交衰退，无脑混血会血脉稀薄。玩家每一次配对都在做真实取舍：**纯度换强度，多样性换未来。** 这直接驱动外交、联姻、掠夺与迁徙。

3. **迁移是被逼出来的，不是选出来的。**
   每个区域的资源是逻辑斯蒂存量，采集速度超过再生速度就会永久性衰减。留下来不是"保守选项"，是慢性死亡。迁徙是重大决策：辎重上限、老弱病残、途中损耗、目的地未知。

4. **灾祸即机会。**
   灾祸从不只是惩罚。魔潮期突变率 ×3（稀有血脉的窗口），兽潮带来海量进化素，严冬筛选出抗寒个体。设计原则：**灾祸是加速进化的赌局，代价是人口。**

5. **每个存档在大陆上留下痕迹。**
   你放弃的旧营地、灭绝部落的遗骸、壁画与图腾，会作为**遗迹**进入世界状态。新存档能遇到上一轮部落的遗骸——种族灭绝不是黑屏结束，是成为别人的考古发现。

## 已经能跑起来的部分

`sim/` 层（纯逻辑、无节点依赖）与验证工具已经实现，可以直接运行：

```bash
# 直接跑游戏（M1 垂直切片：资源仪表 / 谱系规划器 / 迁徙）
./tools/godot.sh

# 无头自检：构建界面 + 走 32 个完整回合（含结束回合链路），约 30 秒
./tools/godot.sh --headless -- --self-test

# 回合制节奏分布（8 个随机大陆）
./tools/godot.sh --headless --script res://tools/debug_pace.gd

# 人格层诊断（性情/爱好/关系/想法/个人史）
./tools/godot.sh --headless --script res://tools/debug_persona.gd

# 字体覆盖检查：把项目里所有文案的汉字逐个验一遍
./tools/godot.sh --headless --script res://tools/check_fonts.gd

# 六种继嗣制度的氏族结构对照
./tools/godot.sh --headless --script res://tools/debug_descent.gd
./tools/godot.sh --headless --script res://tools/debug_reform.gd

# 知识树的发现流程与实际效果
./tools/godot.sh --headless --script res://tools/debug_knowledge.gd

# 单元测试：60 项，约 3 秒
./tools/godot.sh --headless --script res://tools/run_tests.gd

# 遗传平衡模拟：40 次试验 × 260 年 × 20 组配置，约 3.5 分钟
./tools/godot.sh --headless --script res://tools/balance_sim.gd
#   → 输出 reports/balance_report.md

# 快速模式：13 秒，只用于校验判定逻辑
./tools/godot.sh --headless --script res://tools/balance_sim.gd -- --quick

# 逐年诊断单个部落
./tools/godot.sh --headless --script res://tools/debug_tribe.gd
```
